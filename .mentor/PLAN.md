# Rune 计划

学习目标：一次按键如何改变文本缓冲、光标和模式，再变成终端上的画面。

终点：`cargo test` 通过，并且在终端里 `cargo run` 能完成下面的序列。开始是空文档。

1. `i` `h` `i` `Esc`，画面是 `hi`，光标在 `i` 上。
2. `x`，画面是 `h`。
3. `q`，进程退出，提示符正常。

到这里项目就完成。滚动、撤销、更快的缓冲区等终点之后再说。

## 阶段

0. 终端外壳。导师写。raw mode，备用屏幕，`q` / Ctrl-C 退出并恢复。`cargo run -- --smoke` 打印 `rune ready`。
1. 插入一个字符。你写。字符偏移的缓冲区。测试不打开终端。
2. 退格和换行。你写。
3. 光标移动。你写。左右，以及跨行上下。
4. 普通模式和插入模式。你写。`i` 和 `Esc` 切换。按键调用阶段 1–3。
5. 状态变成画面。你写「文本 + 光标 → 行和坐标」。导师写 crossterm 绘制。
6. 把按键接到屏幕上，跑通终点序列。

当前：阶段 1。
